## MVP Implementation Rules

This document defines the **target pricing architecture**. Production
availability must follow actual implemented and certified entitlement
behavior.

-   Free + Starter are the minimum commercially viable plan set.
-   Growth must only be purchasable when its entitlement is correctly
    distinguishable from Starter.
-   Do not delay MVP launch for advanced Growth-only capabilities.
-   Provider-dependent capabilities must be represented truthfully.
-   Public Profile, Publish, Work With Me, Basic Proof, and Share remain
    core growth-loop capabilities.
